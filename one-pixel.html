Try an experiment

Call the darkest pixels “light” and the brightest pixels “dark.” Why can’t this model get a low mistake score?

Reveal the answer

The model has a built-in rule: dark belongs below the cutoff and light belongs above it. Moving one cutoff cannot reverse those sides. A more flexible model would also learn which label goes on which side. Here, the labeling pattern and the model’s rule are incompatible.

Is this how machine learning usually learns?
Yes—the basic loopChoose a model, make predictions, measure errors, and improve or select its settings.
No—the search methodThis demo can exhaustively check 256 cutoffs. Larger models have far too many possibilities. Neural networks often use gradient descent; trees and other models use different strategies.
